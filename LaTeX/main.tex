\paragraph{Motivation théorique (RGG)}
Def informelle : Detection de communautés + spatial graph
Expliquer ce qu'est une communauté
(ensembles de points grandement interconnectés et
faiblement (dans une certaine mesure)connecté intra-communauté )

Origine : \cite{penrose2003random} \cite{gilbert1961random}

Détection de géométrie (et pas de communauté) (Detection problem que l'on abordera pas plus en détail)
