# Annotation 

Dans cette article, les auteurs posent le problème suivant: à partir d’un graphe observé, peut-on décider s’il provient d’un modèle  où les connections observées entre les sommets sont purement aléatoire  (de type Erdős–Rényi) ou d’un modèle où ces conexions ont une structure géométrique cachée ? 

Plutôt que chercher des communautés, les auteurs veulent savaoir si la structure du graphe contirnt une trace statistiquement détectable d'une géométrie sous jacente. Pour ce, ils posent en H0: Le graphe G(n,p) est tel que chaque arête entre deux sommets apparaît de manière totalement indépendante avec une probabilité p, et H1: Le grape G(n,p,d) est géométriqe aléatoire où chaque sommet correspond à un vecteur aléatoire latent placé uniformément sur une sphère de dimension $d$ ($\mathbb{S}^{d-1}$).

Le papier montre que cette question dépend fortement du rapport entre le nombre de sommets $n$ la dimension $d$ et met en évidence des régimes où la géométrie devient indiscernable d’un modèle non géométrique.
